# Apple Design Reference — iOS 26 / visionOS Inspired

## Design Principles
Based on Apple HIG + visionOS extrapolation:
1. **Clarity** — content-first, precise, subtle adornments
2. **Deference** — UI recedes behind content
3. **Depth** — layers, translucency, motion create hierarchy
4. **Immediacy** — direct manipulation, instant feedback
5. **Consistency** — patterns across all screens
6. **Feedback** — every action responds

## Corner Radii (continuous curves)
- Subtle (small controls, badges): 6px
- Standard (cards, buttons, inputs): 10-12px
- Prominent (modals, sheets, panels): 14-18px
- Pill (tags, toggles, chips): 9999px (height/2)
- Avatars: 50% (circle)

Use `border-radius: XXpx` and ensure `overflow: hidden` for clipping.

## Material / Glass System

### Frosted Glass (primary UI chrome)
```css
.glass-panel {
  background: rgba(28, 28, 30, 0.72);
  backdrop-filter: blur(40px) saturate(1.4);
  -webkit-backdrop-filter: blur(40px) saturate(1.4);
  border: 0.5px solid rgba(255, 255, 255, 0.08);
}
```

  backdrop-filter: blur(20px) saturate(1.2);
  -webkit-backdrop-filter: blur(20px) saturate(1.2);

## Animation / Springs

### Spring presets
```typescript
// Standard spring — most UI transitions
spring: { type: "spring", stiffness: 300, damping: 30, mass: 1 }

// Snappy — buttons, small elements
snappy: { type: "spring", stiffness: 400, damping: 25, mass: 0.8 }

// Gentle — sheets, modals appearing
gentle: { type: "spring", stiffness: 200, damping: 25, mass: 1 }

// Bouncy — rubber-band effects
bouncy: { type: "spring", stiffness: 150, damping: 12, mass: 1 }
```

### Duration reference
- Micro-interactions (button press): 0.1-0.2s
- Element transitions: 0.2-0.4s
- Sheet/modal present: 0.4-0.6s
- Page transitions: 0.4-0.7s

### SwiftUI-like spring API (framer-motion / motion.dev)
```tsx
// Enter animation
animate={{ opacity: 1, scale: 1, y: 0 }}
initial={{ opacity: 0, scale: 0.95, y: 10 }}
transition={{ type: "spring", stiffness: 300, damping: 30 }}

// Hover
whileHover={{ scale: 1.02 }}
transition={{ type: "spring", stiffness: 400, damping: 25 }}

// Press
whileTap={{ scale: 0.97 }}

// List item stagger
transition={{ staggerChildren: 0.05, delayChildren: 0.1 }}
```

## Iconography
- SF Symbols style: thin/regular line weight
- Use Lucide or custom SVG inline
- 24×24px standard, 20×20px inline, 28×28px nav bar
- Monoline, 2px stroke, rounded caps

## Layout Patterns

### Translucent Chrome
- Navigation bars, toolbars, sidebars use glass material
- Content scrolls UNDER chrome (not behind opaque bars)
- Safe areas respected (top notch, bottom home indicator)

### Content Structure
- Full-bleed hero areas with safe-area-aware content
- Card-based layouts with elevated surfaces
- Sheet-based navigation for secondary content

### Reduced Motion
- Respect `prefers-reduced-motion`
- Replace spring animations with opacity fades
- Remove parallax and scale effects
- Keep transitions under 0.3s
